## 轨迹与视频对齐调研
- 已对两份本地 Screen Studio 单段区域录制完成只读核验，报告见 `docs/轨迹与视频对齐调研.md`；未修改 Screen Studio 项目、未复制商业素材到本项目、未开发业务代码。
- 两个源 MP4 实测均为 2774×1290，而录制 bounds 为 `(13,152,1387,645)`，因此本样本逻辑坐标到视频像素比例在两个轴都是 2。应通用地使用 `(event - bounds) * (videoSize / boundsSize)`，不能硬编码倍率或使用 `recordingScale`。
- 事件与视频应以同一 display session 的 `processTimeStartMs` 对齐；MP4 PTS 均从 0 开始，时长与元数据只差约 2 ms。不要以首个鼠标事件归零。
- 两个 MP4 都是 VFR，不能由帧号、60 Hz 或名义 FPS 推算时间。解码按 PTS，输出帧按时间插值事件。
- 事件坐标对应光标热点；`cursors.json` 给出热点与标准尺寸，但保存的光标 PNG 像素倍率不统一，且 project.json 含独立光标集和大小设置。第一阶段采用自有光标资源，并用热点偏移定位，不复用商业素材。
